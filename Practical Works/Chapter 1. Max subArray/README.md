# Chapter 1. Max subArray

## Description
Given an integer sequence $a = (a_1, a_2, \dots, a_n)$. A contiguous subsequence of $a$ is defined to be $a_i, a_{i+1}, \dots, a_j$. The **weight** of a subsequence is the sum of its elements. 

Find the subsequence having the highest weight.

## Input
* **Line 1:** Contains an integer $n$ ($1 \le n \le 10^6$).
* **Line 2:** Contains $n$ integers $a_1, a_2, \dots, a_n$ ($-500 \le a_i \le 500$).

## Output
Write the weight of the highest subsequence found.

## Example

**Input:**
> 10
> 3 -1 -3 5 2 5 0 -1 5 4

**Output:**
> 20
